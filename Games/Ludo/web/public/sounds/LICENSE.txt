Ludo sound credits
==================

Three selectable sound sets are bundled. All are real recordings.

1. Recorded table (public/sounds/ludo)
--------------------------------------

Original MoonGames Ludo set, unchanged:

dice-roll.mp3 / dice-roll.ogg
  "Shake and Roll Dice" by Mike Koenig, Attribution 3.0 (CC BY 3.0).
  Edited down from soundbible.com/182-Shake, distributed with tremby/dice:
  https://github.com/tremby/dice/blob/main/public/roll.mp3

move.ogg, capture.ogg
  wooden_01.ogg and wooden_02.ogg from lavenderdotpet/CC0-Public-Domain-Sounds,
  released under CC0 1.0.
  https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds

home.ogg, turn.ogg, start.ogg, win.ogg, foul.ogg
  Beep3, Beep7, Click1, Beep1 and Beep5 from the MMRetro Arcade Sounds Pack in
  lavenderdotpet/CC0-Public-Domain-Sounds, released under CC0 1.0.
  https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds

2. Ludo Original (public/sounds/ludo-original)
----------------------------------------------

Earlier recovered Ludo King APK recordings from sharedassets0.resource. These
are the original SoundManager-style clips that matched the earlier game feel:

  dice.ogg        -> diceSound
  cursor_move.ogg -> CurserMove
  sword.ogg       -> SwordSound
  goal.ogg        -> gamewin
  safe_block.ogg  -> safePoints
  net_time.ogg    -> clocktick
  turn.ogg        -> myturn
  start_game.ogg  -> startGame
  cheers.ogg      -> cheersSound
  net_join.ogg    -> netjoin
  chat-pop.ogg    -> chat-msg
  title_bgm.ogg   -> IntroMusic

3. Ludo Board Pack (public/sounds/ludo-apk)
-------------------------------------------

Exact default board-pack clips from the supplied Ludo King APK:

  clip_roll.ogg   -> roll
  clip_move.ogg   -> move
  clip_kill.ogg   -> capture
  clip_home.ogg   -> token reached home
  clip_safe.ogg   -> safe star / safe box
  clip_die.ogg    -> foul / no legal move
  clip_bg.ogg     -> in-game background music

  start_game.ogg, goal.ogg, rullet_active.ogg, net_join.ogg, chat-pop.ogg and
  net_time.ogg fill the remaining table events from the shared SoundManager.

No clip is used in another clip's place inside a set.

Extraction tooling:
  python-fsb5   https://github.com/HearthSim/python-fsb5
  vgmstream     https://github.com/vgmstream/vgmstream

The attributions above must travel with the game bundle.

Board Packs 2-7 (public/sounds/ludo-board-2 ... ludo-board-7)
-------------------------------------------------------------

These are the remaining complete board sound packs embedded in the supplied
Ludo King APK at assets/SNL/Android/BOARD/bpacksnl2 ... bpacksnl7. Each pack
contains its own clip_roll, clip_move, clip_kill, clip_home, clip_safe,
clip_die and clip_bg. They are bundled as separate selectable sets with their
original clip names and roles. Shared table events use the exact shared asset
clips from Ludo Original (start_game, goal, rullet_active, net_join, chat-pop,
net_time).
