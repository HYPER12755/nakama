Ludo sound credits
==================

All sounds in this folder were extracted directly from the user-supplied
Ludo King APK at ~/unzip/com.ludo.king.apk. They live in the
assets/bin/Data/sharedassets0.resource FSB5 bank inside that APK.

The FSB5 banks were decoded on this device with python-fsb5 and vgmstream,
then converted to OGG/MP3 with FFmpeg. No sounds were recreated or synthesised.
The original recordings belong to the Ludo King game and its publisher; they
are bundled here because the user supplied the APK for this MoonGames build.

Original clip names used here:

  dice-roll.ogg   <- dice (stereo dice roll)
  dice-roll.mp3   <- dice (mono dice roll)
  move.ogg        <- cursor_move
  capture.ogg     <- coins_collect
  home.ogg        <- up_level_medium
  foul.ogg        <- down_level
  turn.ogg        <- turn
  start.ogg       <- start_game
  win.ogg         <- up_level_big

Extraction tooling:
  python-fsb5   https://github.com/HearthSim/python-fsb5
  vgmstream     https://github.com/vgmstream/vgmstream
